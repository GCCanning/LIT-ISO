Tile Variant + Blend Lab

Use this for local, no-credit expansion. Mode A makes new shape-locked tile variants from one approved tile. Mode B makes organic gradients between two tiles for clean biome blending.

1. Choose Source Tiles

2. New Tile Variants

Creates new internal texture/detail while preserving the exact canvas, alpha silhouette, pivot, and tile footprint of Tile A.

3. Gradient Blend Tiles

Creates transition tiles where Tile B gradually takes over from Tile A. Use this for grass-to-dirt, grass-to-stone, snow-to-grass, and biome seams.
