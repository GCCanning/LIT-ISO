Bridge format: Single vs Tileset

Same art, two ways to use it. Drag the slider to feel the difference. Bridges run only along cardinal directions (horizontal E–W shown here; the vertical N–S set uses top/bottom caps identically). No diagonals — the art doesn’t support them.

Wooden plank

A · Single placeable bridge fixed length
One sprite you drop on the map. Simple, but it’s always this exact length — a wider gap needs a different sprite (or it stretches/looks wrong).
B · Tileset bridge any length
End-caps + a repeatable middle tile. Set the span to fit the gap exactly. This is how the .tmx uses them (16px tiles).

A · Single placeable bridge fixed length

End-caps + a repeatable middle tile. Set the span to fit the gap exactly. This is how the .tmx uses them (16px tiles).
span: middle tiles
Quick read: Single = fastest to wire in, fewest assets, but every gap width needs its own sprite. Tileset = a bit more setup (cap + middle + cap, placed along the crossing), but one set covers any span and both orientations — the right call for variable mountain chasms. Both are cardinal-only.
