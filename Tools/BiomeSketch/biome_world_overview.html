▸ World Quality Guide — Why biomes feel noisy & how to fix it

The Noisy World Problem

When every cell independently rolls for props, the result looks like salt-and-pepper scatter. Real landscapes have structure at multiple scales: big zones → clusters → individual plants.

  • Bad: 40% of cells get a random prop
  • Good: 3 grove clusters of density 0.6, surrounded by 70% bare ground

Density Budgets per Biome

Total prop coverage (cells with a prop / total cells):

  • Meadow: 15–20% — flowers + tufts in patches, open lanes
  • Forest: 35–50% inside groves; <8% between (clearings)
  • Mountain: 12–22% rocks scale with height; ores sparse
  • Snow: 8–12% — pines + rocks + fallen logs only
  • Beach: <5% — shore rocks at water edge only

Negative Space = Traversal

Every biome needs clear traversal lanes — paths the player can walk without weaving. The worldgen feature system suppresses props near water edges, paths, and spawn safety zones. Key rules:

  • Carve a cross-shaped clear lane through every chunk first
  • Feature clusters must not block ALL routes through a chunk
  • Small decor (flowers, tufts) can be denser than blocking props

Cluster Before You Scatter

Each prop type should have cluster seeds (blue-noise placed), a radius, and a fill density. Props outside cluster influence = zero chance.

  • Forest grove: radius 5, fillDensity 0.60, 1.8 centers/100, spacing≥7
  • Meadow flower patch: radius 2, fillDensity 0.45, 1.8 centers/100, spacing≥8
  • Rock outcrop: radius 2, fillDensity 0.70, 0.8 centers/100, spacing≥10

Groves should overlap only at edges, never their centers.

Feature Priority & Suppression

Place features in order: Big → Medium → Small. Each feature reserves footprint cells before the next category runs.

  • 1. Tree groves (reserve trunk + surrounding cells)
  • 2. Rock outcrops (reserve 1×1)
  • 3. Bush patches (skip if near tree)
  • 4. Flowers/tufts (skip if near any prop)
  • 5. Decor (can overlap with small decor)

Biome Identity Rules

Each biome should be identifiable at a glance by 1–2 signature features, not all features at equal density:

  • Meadow = flower patches + tufts — no trees; open pastoral feel
  • Forest = plains2 floor + dense grove canopy + clearings carved between
  • Mountain = stratified height bands (rock→grass→alpine→stone) + ores by elevation
  • Snow = open snowfields + lone pines + fallen logs (Gary's desolate feel)
  • Beach = water at h0 + clean sand at h1 — minimal props

If all features fire at the same density, the biome reads as "stuff everywhere."

Transition Quality

The feature density ramp in each biome JSON controls how features fade across the transition band. Key issues:

  • Trees should fade out 4–7 cells before biome border
  • Accent tiles (flowers, leaf litter) should cross-fade across the same band
  • No abrupt prop wall at the biome edge

Tune this in Biome Preview + Editor using the accent rate and grove density sliders.

How to Use This Tool

  • Use ⟳ Reroll All to see many seeds — if most look noisy, the density rules need fixing
  • Drag the Prop density slider left to see the target "sparse" look
  • Click a biome canvas to focus it larger; right-click to reroll just that biome
  • Click Open Editor → on any biome to open the full tile/prop editor
  • Save reference vignettes in Biome Sketch (freehand) once you have a look you like
