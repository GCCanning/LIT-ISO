  (`%LOCALAPPDATA%\Unity\Editor\Editor.log`) or **batchmode**. The owner play-tests.

  (CS0246). To verify a new file: add a `<Compile Include=...>` line to the generated `.csproj`
  and rebuild (Unity overwrites it later). Headless compiler: `C:\Projects\dotnet-sdk\dotnet.exe`.
- **Commit per logical unit**, compile-check first, never to `main`. Binaries via Git LFS
  (`.gitattributes`). Worldgen changes need a **NEW world** to take effect.
- **Invariants — do NOT "fix":** IsometricZAsY, cellSize (1,0.5,1), sort axis (0,1,-0.26),
  TilemapRenderer Individual, Height_N=layer 10+N, world-query movement, maxWalkStepHeight=1.

## 2. Key systems (current state)
**Biomes — `Assets/StreamingAssets/worldgen/biome_suite.json` is the SINGLE source of truth.**
8 biomes (plains, forest, badlands, frozenmountain, snow, marsh, grotto, sunspool). `BiomeSuiteLoader`
(`Assets/Scripts/IsoCoreFoundation/World/BiomeSuiteLoader.cs`, JsonUtility) loads it at the end of
`FoundationContent.BuildDefault` and applies climate rectangles (t/m/e) + priority + fallback + mobs
+ tiles onto `BiomeDefinition`. Tiles are imported as `bt_<biome>_<basename>` in `Assets/Resources/Tiles`
(import script: `scratchpad/import_biome_tiles.py`; block-id rule must match `BiomeSuiteLoader.BlockId`).
`IsoTerrainSampler.SelectBiome` uses a **smooth low-freq climate-elevation** (not terrain height) so
biomes are large with clean borders; there's a thin **dithered border blend** (BiomeIndexAt + ~22%).
Logs `[BiomeSuite] applied 8/8 biomes` at startup. Adding a biome = edit the JSON only.

**Abilities — `Assets/Scripts/IsoCoreFoundation/Progression/FoundationAbility*`.**
6+1 abilities in `FoundationContent`: steady_strike(Melee), guard_step/stone_skin(SelfBuff),
mana_bolt/ember_spark/root_snare(Projectile), **flash_step(Blink)**. The `delivery` field was the
big bug — it defaulted to Melee and was never set, so nothing happened; now wired. `FoundationAbilityLoadout`
default slots = flash_step/mana_bolt/ember_spark/steady_strike; persisted slots validated vs AllIds.
The dispatcher plays an instant cast-flash at the caster + the LPC body anim (slash/spellcast; NONE
for Blink). Casts go: AbilityWheelView (Q/E/R/F) → FoundationAbilityLoadout.Cast → Abilities.TryUseAbility
→ AbilityDispatcher.Execute.

**Player animation — `PlayerAnimator` (placeholder 8×4 idle/walk) is REPLACED at runtime by
`LayeredCharacterAnimator` (LPC)** via `LayeredCharacterPlayerHook` when the LPC wardrobe is present.
LPC supports one-shots: **slash / spellcast / thrust / shoot / hurt** (`PlayOneShot`). Foundation combat
code drives them through the **`ICharacterActionAnimator`** interface (`IsoFoundationPlayer.PlayBodyAnim`)
— same cross-assembly pattern as `IDamageable`. (Owner says LPC "should have" attack/cast/hurt rows.)

**Input — `IsoFoundationPlayer` + `PlayerInteraction`.** Owner direction: **Left-click = always
ATTACK + use items/tools; Right-click = interact; movement is WASD (click-to-move disabled).**
Attack = LPC sideways slash + WorldFx slash arc + held-tool swing (tool only) + damage. Z is a
fallback attack key.

**Mob animation — `Assets/Scripts/IsoCoreFoundation/Mobs/Mob.cs` `LoadAnimation`.** Loads
`Resources/<folder>/<prefix>-<state>-<i>` for states **idle/move/hurt/die** (max 4 frames),
**single-direction**, picked by `IsMoving`. Mapped ids: `slime` + `slime_*` (variants),
`bandit`, `adventurer_*`, `predator_plant_*`. Mobs compute `_faceDir` toward target but the sprite
does NOT turn (single-direction frames only). Mob sprite size = native PPU (no scale); shadow uses sizeUnits.
