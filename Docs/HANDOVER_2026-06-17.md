## 0. What this project is

**LIT-ISO** — a Unity **6.3** 2D **isometric** (IsometricZAsY) cozy **survival / crafting / building
LitRPG**. Clean-room clone of *ISO-CORE*'s structure (never its content). The canonical game is the
**`IsoCore.Foundation`** assembly (`Assets/Scripts/IsoCoreFoundation/`); the legacy `Assembly-CSharp`
is being retired. **You own the whole codebase** (ignore old "Codex/second-agent/lanes" references).

**Render pipeline: Built-in (NOT URP).** This is load-bearing — Unity 2D Lights / normal-map lighting
/ ShadowCaster2D are URP-only and unavailable without a full (risky) migration. Lighting is faked
(additive sprites + a global day/night tint shader).

## 1. Hard rules / invariants (do NOT "fix" these)

- Grid `IsometricZAsY`, `cellSize (1, 0.5, 1)`; `IsoGrid` is the single source of coord + sort math.
- Sorting: `-(cx+cy)*64 + height*8 + entityLayer`; `transparencySortAxis (0,1,-0.26)`;
  **`TilemapRenderer.mode = Individual`** (Chunk mode hides characters behind tiles).
- Height: `Height_N` = Unity layer `10+N`; player sorting layer `10+height`; height lifts visual Y by
  `IsoGrid.HeightStep (0.3125)`.
- **Movement is world-query based** ("ask the world, don't push physics"); foot collider trigger-only;
  `maxWalkStepHeight=1` (walk one step up, jump for taller cliffs).
- **`FoundationBootstrap` is the ONLY constructor** of world/player/inventory/systems (its `Awake()`
  builds the entire runtime graph). One inventory instance, passed explicitly.
- Git: branch off `main` (`feat/<task>`), small PRs, never commit to `main`. Binaries via Git LFS.
- Ship **PixelLab/BiomeSketch-generated** original art; fill gaps to that style.

## 2. Architecture map (where things live)

`Assets/Scripts/IsoCoreFoundation/`:
- **Core/** — `FoundationBootstrap` (runtime graph), `FoundationContent` (ALL data: blocks, items,
  recipes, nodes, mobs, biomes, abilities, classes, professions, quests), `FoundationConfig`
  (worldgen + tunables), `IsoGrid`, `FoundationTypes` (enums), `FoundationSpriteScale` (new).
- **World/** — `IsoTerrainSampler` (terrain + biome assignment + decoration placement),
  `IsoSettlementSampler` (settlements), `IsoWorld(Controller/Renderer)`, `AmbientLightController`,
  `FoundationWeatherVisuals`, `WindSway` (new), `WorldFx`.
- **Player/** — `IsoFoundationPlayer` (movement + `Blink`), `PlayerInteraction`, `PlayerAnimator`.
- **Progression/** — `FoundationProgression` (stats/XP/affinities/Trial evidence/classes/professions),
  `FoundationAbilitySystem` + `FoundationAbilityDefinition` + `FoundationAbilityDispatcher` (new) +
  `FoundationProjectile` (new).
- **Mobs/** — `Mob`, `MobSpawner`, `SettlementTownsfolkSpawner` (new), `MobDefinition`.
- **Harvesting/** `ResourceNode` · **Building/** `PlacementSystem`/`PlaceableInstance` ·
  **Crafting/** · **Farming/** · **Dungeons/** · **Survival/** (camping) · **UI/** (HUD/pause/map).
- **Editor/** — `FoundationValidator`, `FoundationIntegratedSliceValidator`, importers.
UI (uGUI HUD) lives in `Assets/Scripts/UI/InGame/` (`LitIso.UI.InGame`), bound on `FoundationBootstrap.Ready`.

## 6. Known issues / watch-outs

1. **Untested code (§4)** — compile + play-test before building more. A single compile error hides
   new editor menus and breaks the whole game (this bit us — the fence-slice menu never appeared).
2. **Height is rare** — `continentTier2/3/4Level` (0.62/0.74/0.85) gate elevation high; lower them or
   raise `heightFrequency` for more hills/cliffs. Owner wants more visible elevation.
3. **Half the Bible biomes aren't real** — desert is dead code (climate ranges never set), mountain
   height strata unimplemented; Sunspool/Marsh/Glowcap don't exist (see doc 29/30). Owner chose to
   **polish the 5 live biomes first** (meadow/forest/snow/beach/mountain) and generate the rest later.
4. **Biome placement** — only B1.1 (negative space) is done; the bigger wins (one dominant cover per
   zone + per-biome prop ladders + wiring the authored `biome_suite.json`) are pending (doc 30 B1.2/B2).
5. **Mob/humanoid appearance scaling** isn't applied — humanoid NPCs are dressed by an external
   (Assembly-CSharp) character creator that ignores `sizeUnits`.
6. **Tall/multi-cell building sorting** uses a single sort value at the anchor cell → player clips
   in front of/behind whole buildings. Fix = per-row "slice" sorting (the ISO-CORE devlog technique).
7. **Lighting** (normal-map depth, point lights) needs either URP migration (large/risky) or a custom
   Built-in lit shader. Pros/cons + estimate are in the chat history; not started.
8. Many tuned values (cliff shade, sprite `heightUnits`, biome `ClearingCut`) are **first-pass** —
   eyeball and nudge.
9. **Worldgen changes need a NEW world** to take effect (generation-time).

## 7. How to verify

1. Open in **Unity 6.3**; let it compile (fix any console errors first).
2. Editor validators: `Tools/LIT-ISO/ISO-Core Foundation/Validate Foundation` and the integrated
   slice validator (`FoundationIntegratedSliceValidator`).
3. Play `Assets/Scenes/IsoCoreFoundation.unity` (or Menu → New Game). Checklist: abilities cast on
   Q/E/R/F; spawn beside a hamlet; townsfolk wander town roads; cliffs read as shaded; vegetation
   sways; biomes have open/bare ground.
